HEAT-SIGNAL
NASA Space Apps Challenge: Earth System Trend Detective

FILES
index.html: website structure and navigation
style.css: visual styles and responsive layout
app.js: NASA POWER data requests, charts, comparisons, and trend calculations

OPEN THE SITE
Keep all four files in the same folder. Open index.html in a modern web browser. The NASA POWER data views require an internet connection. If the browser blocks API requests from a local file, host the folder with a static website host such as GitHub Pages.

DATA AND LIMITS
The site requests monthly meteorological data from the NASA POWER API. The meteorological data are based on the MERRA-2 assimilation model and use a broad grid resolution. They are not direct measurements at each selected city. Trend estimates describe the selected record and do not establish a cause.
