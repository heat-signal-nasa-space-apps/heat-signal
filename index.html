WHAT THIS TEST SAYS

The exact Student t-test p-value tests whether an annual linear trend differs from zero. Mann–Kendall uses tie correction and lag-1 trend-free prewhitening. Statistical significance describes evidence in this record; it does not measure the size or importance of the change.

READ WITH CARE

Grid-scale, model-based air temperature describes broad conditions—not a street, field, or thermometer. The confidence interval captures regression uncertainty, not every data or model uncertainty.

RECORD & UNITS

1981–2025 · degrees Celsius

The default request covers complete calendar years, ending in 2025. POWER's meteorological grid is 0.5° latitude × 0.625° longitude (roughly 50 km). Locations are representative grid points, not precise local observations.

ANALYSIS

Remove seasonality before fitting

Monthly values are averaged into calendar-year means. A linear regression on annual means estimates °C per decade. The 95% interval uses the regression standard error and a t critical value; the two-sided t-test evaluates a zero slope.

For records with at least 10 years, we also report the tie-corrected Mann–Kendall test after lag-1 trend-free prewhitening (TFPW), which reduces sensitivity to ties and short-range serial correlation while retaining the monotonic-trend interpretation.

LIMITATIONS

A useful signal, not the whole story

MERRA-2 is model-based and has spatial uncertainty. Grid spacing limits local interpretation. Annual averaging hides within-year extremes. The regression confidence interval assumes independent annual residuals. Mann–Kendall uses lag-1 trend-free prewhitening, which does not remove every possible serial-correlation effect. A significant trend does not establish cause.
